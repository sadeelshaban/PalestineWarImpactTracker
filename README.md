# 🇵🇸 Palestine War Impact Tracker

**Palestine War Impact Tracker** is a Java desktop application that documents and analyzes the humanitarian and social impacts of war in Palestine. The system provides a graphical interface to enter, view, and evaluate data related to war victims, affected regions, healthcare, education, and border status.

---

## 🧠 Overview

This application helps visualize and manage war impact data through multiple screens, allowing:

- Adding personal data of war victims
- Analyzing healthcare and education damage
- Viewing the most affected areas
- Tracking border statuses and overall war statistics

Built with **Java (JDK 17)** and developed in **Eclipse IDE**, it features a clean user interface and modular design.

---

## 💻 Features

- 📝 Add and view records of affected individuals  
- 📈 Analyze regional statistics and visualize trends  
- 🏥 Healthcare and 🎓 education impact evaluation  
- 🌍 Most affected region tracking  
- 🛂 Border status updates  
- 🖼️ Background visuals and GUI interaction  

---

## 🚀 How to Run

### Requirements
- Java JDK **17**
- Eclipse IDE or any Java-compatible IDE

### Running the App
1. Open the project in **Eclipse** or another IDE.
2. Ensure the JDK is set to version 17.
3. Locate and run the main class: `App.java` or `WelcomeScreen.java` inside the `src/` directory.
